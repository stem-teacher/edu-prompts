

# Stage 5 Data Science 2 Curriculum Development Brief (Year 10, Ages 15–16)

## Purpose and Overview

You are tasked as an expert curriculum developer to design a comprehensive 10-week Data Science 2 program for Year 10 students in a selective school.

This program must:
- Fully align with the NSW Stage 5 Science Syllabus and the Australian Curriculum: Science (Version 8.4), with specific focus on the 'Data Science 2' content area, as detailed in the official ‘Science 7-10: Data Science Guide and Scope & Sequence’.
- Build upon the attached Educational Knowledge Graph (EduKG), as well as provided research reports.
- Integrate best-practice pedagogical principles, especially cognitive load management and neurodiversity-aware methods.

All curriculum content and learning outcomes must be directly and accurately aligned with the ‘Data Science 2’ section. Each lesson must reference the exact EduKG and syllabus elements it covers.

## Guiding Principles

Drawing from the EduKG and research evidence, core principles must shape curriculum and lesson design:
- Hands-on learning: Activities must actively engage students with real data science processes.
- Scientific inquiry: Promote question-driven, investigative engagement with data.
- Data representation and visualization: Develop students’ ability to communicate and interpret data effectively.
- Numeracy skills: Reinforce and apply mathematical concepts in data science contexts.
- Integration of digital tools: Use the Observable open-source framework and AI-powered assessments and feedback.
- Real-world analysis: Focus on analysing authentic, societally relevant data using modern data science tools.

## Deliverables

Six curriculum components must be developed using supplied templates.

### 1. Course Plan
- Provide a 10-week schedule detailing topics and learning objectives for each week.
- Explicitly show which syllabus and EduKG elements are addressed each week.
- Enable a coverage matrix that demonstrates all lessons together cover all mandated items.
- Explain how the five elements of Load Reduction Instruction (worked examples, completion tasks, split-attention reduction, goal-free tasks, reduction of redundant information) are applied throughout.
- Describe strategies supporting deep memory encoding and socio-emotional learning skills.
- Deliver the plan in both JSON and Markdown formats.

### 2. Detailed Lesson Plans
For each of the three weekly classes (total 30 lessons):
- Title and curriculum-aligned learning outcomes.
- Overview connecting purpose to data science and scientific inquiry.
- Activities, including:
  - Warm-up exercises
  - Main activities (hands-on work, group work, data science framework tasks, Python exercises in AI notebooks)
  - Reflection and discussion
- Formative assessments (quizzes, AI-generated questions, in-class tasks)
- Student workbook exercises, especially in Observable notebooks
- Extension activities for advanced learners

### 3. Lesson Materials
Outline required materials, including:
- Slide decks (visual presentations)
- Handouts and supplementary notes
- Online workbooks (Observable format)
- Python-based exercises in AI-assisted notebooks

### 4. Automated Assessment Strategy
Specify methods for AI and digital tool-driven assessment:
- Summative assessments: AI-generated multiple choice and open-ended questions, real-world data applications
- Interactive review sessions using AI-powered feedback

### 5. End-of-Semester Exam
Describe the exam structure and automated grading:
- Format: Data analysis tasks, graph interpretation, real-world simulations
- Grading: Automated using AI and workbooks

### 6. AI Integration
Explain AI integration, including:
- AI Assistant for student support (voice and chat)
- AI Review System for detailed feedback
- Study summaries: Weekly AI-generated recaps for revision

## Alignment and Mapping

Each lesson must list the syllabus and EduKG elements covered so a coverage matrix can be generated. This ensures all mandated content is explicitly taught, with mapping across both NSW and Australian Curriculum frameworks as outlined in ‘Data Science 2’.

## Pedagogical, Neurodiversity, and Cognitive Load Considerations

- Apply the five elements of Load Reduction Instruction across all lessons.
- Promote deep memory encoding using active recall, spaced retrieval, and dual coding.
- Integrate socio-emotional learning (collaboration, reflection, ethical awareness).
- Ensure accessible technology and activities for all student learning needs.

## Additional Notes

- Use provided curriculum, lesson plan, and assessment templates.
- Address issues of equity, accessibility, or digital inclusion.
- Reference authoritative documentation for all major tools and ensure students are supported in their use.

## Summary

Develop an innovative, implementable Stage 5 Data Science 2 curriculum that aligns fully with the NSW and Australian curricula. Build from the EduKG and syllabus, connect every lesson and assessment to these frameworks, and document all required mappings for trackability and educational success.
